**Один найденный и исправленный в процессе баг** — `Run.Text` в WPF по умолчанию

новые `<Run>` с биндингом на `Loc` — не забудь `Mode=OneWay` сразу.

## Как проверялась работа в прошлых сессиях (нет своего CLI-тула, только это)

Для живого прогона (сборка + запуск + клики + скриншоты) использовался PowerShell +
`System.Windows.Automation` + `System.Drawing` (скриншот окна по hwnd через
`GetWindowRect`/`Graphics.CopyFromScreen`). Рабочие скрипты этой сессии — временные, не в
репозитории, пересобирались заново по описанию:
`Add-Type -AssemblyName UIAutomationClient, UIAutomationTypes` + `Find-ByName`/
`Find-ByAutomationId`/`Invoke-Element` (`InvokePattern`)/`Select-RadioElement`
(`SelectionItemPattern`)/`Get-TextBoxValue` (`ValuePattern`). Важные нюансы:
- **Окна, открытые с `Owner = this`, оказываются в дереве UI Automation детьми
  окна-владельца, а не корня рабочего стола** — `AutomationElement.RootElement.FindFirst`
  их не находит; искать нужно и как ребёнка окна-владельца, и (fallback) как ребёнка
  root — см. `GuideWindow`/`SettingsWindow`, открытые с `Owner`. `AdminWindow` открывается
  без `Owner` (`new AdminWindow(_config).Show()`), поэтому оно — прямой ребёнок root.
- **`PasswordBox` блокирует `ValuePattern`** — пароль вводится через `SetFocus()` +
  `System.Windows.Forms.SendKeys::SendWait(...)`, не через `ValuePattern.SetValue`.
- **Скрипты обязательно сохранять как UTF-8 с BOM** (`New-Object System.Text.UTF8Encoding($true)`
  + `[System.IO.File]::WriteAllText`) — без BOM `powershell.exe` (Windows PowerShell 5.1,
  не `pwsh`) читает кириллицу как ANSI и падает с ошибками парсера на русских строковых
  литералах.
- **Копировать в рабочую папку весь `bin/Debug/net8.0-windows`, не только `.exe`** — framework-
  dependent сборка без остальных `.dll`/`.deps.json`/`.runtimeconfig.json` падает сразу при
  старте с "The application to execute does not exist: ...VanillaLauncher.dll".
- **`AppConfig.Language` персистится между запусками exe в одной и той же рабочей папке** —
  если тестовый скрипт переключил язык (кнопка сохраняет `_config.Save()`), следующий запуск
  из той же папки унаследует этот язык. Пересоздавай рабочую папку (`rm -rf` + свежий `cp -r`
  из `bin/Debug/net8.0-windows`) перед каждым независимым тестовым сценарием, если важно
  начинать с чистого/дефолтного состояния.
- Для диагностики XAML-исключений временно меняй `e.Exception.Message` на `e.Exception.ToString()`
  в `App.OnDispatcherUnhandledException` (см. `App.xaml.cs`) — полный стектрейс с номером
  строки/позиции почти всегда сразу указывает на причину; не забудь вернуть обратно перед
  коммитом.
- GitHub Actions runs проверяются напрямую через
  `api.github.com/repos/Pewdoloco/khanneli-local-launcher-minecraft/actions/runs`
  (без токена, публичный репозиторий).
